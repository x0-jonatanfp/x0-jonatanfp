### 🐧 ¿En qué ando metido?

- **Infraestructura y SysAdmin:** Gestiono mi propio servidor web y servidor de correo. Configuro servidores **Ubuntu** y automatizo tareas creando scripts para entornos empresariales o personales en Bash.

- **Frontend & UI:** Construyendo interfaces rápidas y modernas con **Astro**, **React**, **Tailwind CSS** y **Bootstrap**.
- **Data:** Gestión de bases de datos con **PostgreSQL**.
- **Diseño 3D & Modding:** Modelado y exportación con **3ds Max** y **Blender** para crear contenido único en **Assetto Corsa**.
